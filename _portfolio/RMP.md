Our robot had to transport a cylindrical flag across the map and also collect and deposit cubes for points. I designed the gripper system to reliably handle both geometries with a single mechanism.

### What I worked on
- Mechanical design of an adaptive gripper for multiple object geometries
- Integration with the robot mobility platform
- Testing and iteration to improve grip reliability

### Key design considerations
- Handling both cylindrical and cuboid objects
- Secure grip while navigating obstacles
- Simple, reliable actuation

### Result
- Successful object transport across the obstacle course
- Robust gripping across different shapes without mechanism changes
